# Security

[简体中文](<SECURITY.zh.md>)

Do not put access tokens, private session content or working exploit details in a public issue or pull request.

If this repository’s Security tab offers **Report a vulnerability**, use it to send a private report. Include the affected plugin and DSH versions, reproduction steps, expected impact and a minimal example with private data removed.

If private reporting is unavailable, open an issue asking how to contact a maintainer privately. Leave out vulnerability details until a private channel is agreed.

There is no published security support window or response-time commitment. Include your installed version so a maintainer can assess the report.
